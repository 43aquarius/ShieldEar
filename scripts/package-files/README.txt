【一、快速开始（三步）】
  1. 将本文件夹解压到任意本地目录（路径不要含特殊符号）
  2. 双击「START-ShieldEar.bat」
  3. 等待 3~8 秒，浏览器自动打开 http://127.0.0.1:3000
     （若未自动打开，手动访问该地址即可）

  关闭黑色命令行窗口即退出平台。

【二、纯离线说明（核心特性）】
  本版本为「纯离线发行版」，不含任何云端功能：
  · 合成挑战的语音合成仅使用内置 espeak-ng 本地引擎；
  · 启动与运行全程不发出任何网络请求（零联网·零尝试·零等待）；
  · 云端合成通道已从本包中整体移除（界面不提供开关）；
  · 实时鉴听、文件检测、案例存证、证据导出均为本地能力；
  · 全部依赖（Node.js 运行时、espeak-ng、SQLite 数据库、
    检测引擎校准数据）均已内置，无需安装任何软件；
  · 在完全断网（拔网线/关 WiFi）的电脑上可完整运行全部功能。

【三、本版修复与新增】
  v1.3.7 修复：
  · 解决部分 Windows 电脑上「系统自检」提示本地合成引擎失败、
    合成挑战报「未找到可用的 espeak-ng」的问题（根因：这类电脑
    未安装微软 VC++ 2015-2022 运行库，导致内置合成器无法启动；
    现已将官方运行库 DLL 随包内置，任何 Windows 10/11 电脑解压
    即用，无需安装任何运行库）；
  · 界面精简：移除「真伪 A/B 对比试听」卡片，合成挑战页签聚焦
    现场合成主线。

  v1.3.6 修复：
  · 解决 v1.3.5 在 Windows 上启动后「案例库加载失败」「合成
    挑战失败」等报错的问题（根因：打包时一个内部依赖链接未随
    包携带，现改为实体文件随包，并新增交付完整性自检）；

  v1.3.5 新增：
  · 系统自检（顶部导航第 4 项）：一键体检数据引擎、证据目录、
    引擎校准、本地合成引擎、离线声明，逐项打勾，全绿即就绪；
  · 证据完整性核验：在检测结果「证据固定」卡片或案例库详情中
    点击「核验证据完整性」，平台将重读证据音频并重算 SHA-256
    与入库值比对，绿色印章证明证据自存证以来未被篡改；
  · 启动自检：启动时若发现关键组件缺失，会给出明确中文提示
    并写入 STARTUP-ERROR.txt，不再出现含义不明的页面报错；
  · 全部接口错误已人话化（不再出现 Internal Server Error 裸文）。

【四、常见问题】
  Q1: 双击后窗口一闪而过？
      → 请先查看文件夹根目录是否生成了 STARTUP-ERROR.txt；
        若有，按其中提示处理（通常为解压不完整或杀毒误删）；
        也可右键 bat → 以管理员身份运行，或打开 cmd 把 bat
        拖进窗口回车查看报错信息。

  Q2: 浏览器打不开页面？
      → 等待 10 秒后刷新；确认地址是 127.0.0.1:3000；
        若 3000 端口被占用，右键 bat 编辑 PORT=3001 等其他端口。

  Q3: 杀毒软件提示？
      → node.exe 为微软官方 Node.js v20.18.1 原版二进制，
        espeak-ng.exe 来自 espeak-ng 官方 1.52 发行版，
        espeak-ng 目录下的 msvcp140.dll / vcruntime140.dll 等
        为微软官方 VC++ 运行库，均可放行；本平台不向外部发送
        任何数据。

  Q4: 想重置演示数据？
      → 删除 server/db/custom.db 后重启（将自动重建空库，
        案例库将清空；内置演示案例可在案例库重新生成）。

  Q5: 页面提示「案例库加载失败」？
      → 先在顶部导航打开「系统自检」：若数据引擎项未通过，
        说明数据库文件损坏或被占用，按 Q4 重置即可。

【五、目录结构】
  START-ShieldEar.bat   一键启动脚本
  node.exe              内置 Node.js v20.18.1 运行时（官方原版）
  espeak-ng\            本地语音合成引擎（espeak-ng 1.52 官方版
                       + 微软 VC++ 运行库 DLL，免安装）
  server\               平台服务端（Next.js standalone 构建）
    ├─ boot.js          启动包装器（启动自检 + 数据库路径定位）
    ├─ db\custom.db     SQLite 案例库存证数据库（含演示案例）
    ├─ evidence\        存证证据 WAV 文件
    └─ public\          前端静态资源与预置样本

【六、技术要点】
  · 检测算法：多维声学特征（基频微扰/频谱倾斜/谐波能量/
    共振峰带宽/调制深度等）+ 加权证据融合，全程本地计算；
  · 证据链：原始音频与 16kHz 分析副本双向 SHA-256 锚定，
    支持一键完整性核验（重算哈希比对），存证包可离线导出；
  · 引擎与版本信息在每条存证记录中如实标注。
