【一、快速开始（三步）】
  1. 将本文件夹解压到任意本地目录（路径不要含特殊符号）
  2. 双击「START-ShieldEar.bat」
  3. 等待 3~8 秒，浏览器自动打开 http://127.0.0.1:3000
     （若未自动打开，手动访问该地址即可）

  关闭黑色命令行窗口即退出平台。

【二、纯离线说明（核心特性）】
  本版本为「纯离线发行版」，不含任何云端功能：
  · 合成挑战的语音合成仅使用内置 espeak-ng 本地引擎；
  · 启动与运行全程不发出任何网络请求（零联网·零尝试·零等待）；
  · 云端合成通道已从本包中整体移除（界面不提供开关）；
  · 实时鉴听、文件检测、案例存证、证据导出均为本地能力；
  · 全部依赖（Node.js 运行时、espeak-ng、SQLite 数据库、
    检测引擎校准数据）均已内置，无需安装任何软件；
  · 在完全断网（拔网线/关 WiFi）的电脑上可完整运行全部功能。

【三、本版修复与新增】
  v1.3.10 修复（重要 · 合成挑战音色与中文朗读）：
  · 修复「七个音色合成出同一个声音」：上一版合成命令中音色
    参数被硬编码为单一中文声部（cmn），界面选的音色从未生效。
    现按音色映射到不同的声部变体 + 音高 + 基准语速（沙箱实测
    七音色两两互异，女声组基频 176–250Hz、男声组 80–110Hz）；
    引擎标签（如「espeak-ng 本地合成 · cmn+f2」）如实标注；
  · 修复「合成语音完全不是正常能听的语音」：合成文本此前经
    命令行参数传给合成器，在中文 Windows 上会经过 ANSI 代码页
    （GBK）转换，而合成器按 UTF-8 解读，中文必成乱码（PE 导入
    表实证：该程序从 CRT 取窄字符参数，无 UTF-16 命令行感知）。
    现改为文本经标准输入以 UTF-8 字节流直传，绕开代码页，
    跨平台行为一致；
  · 由此，界面里连选两个音色入库将产生声学互异的真实样本，
    不再出现「同声重复案例」。

  v1.3.9 修复（重要 · 应用内合成通道根因修正）：
  · 彻底修复「应用内合成挑战始终回放预置样本」的问题。真正
    根因（真机审计坐实）：构建工具（Turbopack）在打包时把
    「是否 Windows」的判断按【构建机】（Linux）写死为否，
    导致源码中正确的 espeak-ng.exe 候选名在产物里退化为裸名
    espeak-ng —— 应用永远找不到包内的合成引擎。v1.3.1 以来的
    所有发行包均受此影响（v1.3.7 真机自检 4/5 红项同源）；
    v1.3.8 修的是 DLL 文件名（那也是真实存在的问题），但未
    触及本根因，故界面上的合成挑战依旧回放；
  · 修复：候选探测改为平台无关（按文件名直接探测，不再依赖
    任何平台判断）+ 启动时全局注入 ESPEAK_DATA_PATH + 打包
    流水线新增「平台折叠硬闸」（产物中必须能找到 espeak-ng.exe
    字样，否则拒绝打包）；
  · 修复并发存证缺陷：两个检测同时提交时，旧版会互相覆盖对方
    的证据音频（仅事后点核验才能发现哈希不一致）。现改为
    「先入库占号、后写文件」，从机制上杜绝覆盖；
  · 修复浏览器重采样导致判决跨档的问题：同一段音频若以
    44.1/48kHz 容器提供（如手机导出），旧版判决会从「深伪检出」
    掉到「疑似合成」。现改为单次高质量抗混叠重采样，跨采样率
    判决稳定（回归实测分差 ≤ 0.003）；
  · 新增「存证包 (ZIP)」一键导出：检测结果页与案例库详情可
    下载包含证据音频、原始来源文件、案例全量记录、完整性核验
    报告与 SHA-256 清单的离线存证包（此前版本仅为浏览器打印）；
  · 原始上传文件随证落盘：文件检测的原始音频（≤12MiB）现在
    会作为证据保留，核验页的「原始来源文件」检查真正可执行
    （此前恒为跳过）；来源哈希改为服务端自行计算，不信任
    客户端声明值；
  · 预置挑战音频去重：7 个音色的预置样本不再与演示诈骗样本
    重复（此前彤彤/落多两条为同一文件的拷贝）。

  v1.3.8 修复：
  · espeak-ng.exe 导入表要求 libespeak-ng.dll（连字符）而包内
    为下划线名导致 0xC0000135 —— 双文件名随包 + 自动补齐 +
    PE 导入表打包硬闸（详见上版说明，本版保留全部机制）。

  v1.3.7 修复：
  · VC++ 2015-2022 运行库三 DLL 随包分发（v1.3.9 起增放到
    包根与 Prisma 引擎目录，未装运行库的机器数据引擎亦可加载）。

  v1.3.5 新增：系统自检、证据完整性核验、启动自检（保留至今）。

【四、常见问题】
  Q1: 双击后窗口一闪而过？
      → 请先查看文件夹根目录是否生成了 STARTUP-ERROR.txt；
        若有，按其中提示处理（通常为解压不完整或杀毒误删）；
        也可右键 bat → 以管理员身份运行，或打开 cmd 把 bat
        拖进窗口回车查看报错信息。

  Q1b: 自检/合成报 0xC0000135 或「未找到可用的 espeak-ng」？
      → 这是包内 espeak-ng 目录的 DLL 缺失或文件名不匹配，
        不是缺少 VC++ 运行库（请勿去装运行库，装了也没用）；
        请双击包根目录「windows-smoke.cmd」一键定位/自动修复，
        或重新下载解压完整发行包。

  Q2: 浏览器打不开页面？
      → 等待 10 秒后刷新；确认地址是 127.0.0.1:3000；
        若 3000 端口被占用，右键 bat 编辑 PORT=3001 等其他端口。

  Q3: 杀毒软件提示？
      → node.exe 为微软官方 Node.js v20.18.1 原版二进制，
        espeak-ng.exe 来自 espeak-ng 官方 1.52 发行版，
        espeak-ng 目录下的 msvcp140.dll / vcruntime140.dll 等
        为微软官方 VC++ 运行库，均可放行；本平台不向外部发送
        任何数据。

  Q4: 想重置演示数据？
      → 请勿删除 server/db/custom.db —— 本包【不会】自动重建
        数据库，删除后将无法启动（启动自检会明确报错并拒绝
        启动）。如需恢复初始状态：从发行包 zip 重新解压
        server/db/custom.db 与 server/evidence/ 两个文件/目录
        覆盖即可；案例也可在界面「案例库」中逐条删除。

  Q5: 页面提示「案例库加载失败」？
      → 先在顶部导航打开「系统自检」：若数据引擎项未通过，
        说明数据库文件损坏或被占用，按 Q4 从发行包恢复。

【五、目录结构】
  START-ShieldEar.bat   一键启动脚本
  windows-smoke.cmd     本地合成引擎冒烟自检（10 秒 · 可修复旧包；
                        仅验证包内引擎自身，应用内端到端状态
                        请以「系统自检」页与合成挑战为准）
  node.exe              内置 Node.js v20.18.1 运行时（官方原版）
  espeak-ng\            本地语音合成引擎（espeak-ng 1.52 官方版
                       + 微软 VC++ 运行库 DLL，免安装；
                       libespeak-ng.dll 与 libespeak_ng.dll
                       双文件名并存，v1.3.8 修复）
  server\               平台服务端（Next.js standalone 构建）
    ├─ boot.js          启动包装器（启动自检 + 离线锁 +
    │                   ESPEAK_DATA_PATH 全局注入，v1.3.9）
    ├─ db\custom.db     SQLite 案例库存证数据库（含演示案例，
    │                   请勿删除 —— 本包不自动重建）
    ├─ evidence\        存证证据文件（16kHz 证据 WAV + 原始来源）
    └─ public\          前端静态资源与预置样本

【六、技术要点】
  · 检测算法：多维声学特征（基频微扰/频谱倾斜/谐波能量/
    共振峰带宽/调制深度等）+ 加权证据融合，全程本地计算；
  · 证据链：原始来源文件与 16kHz 分析副本双向 SHA-256 锚定，
    支持一键完整性核验（重算哈希比对）；
  · 存证包：任一案例可导出离线 ZIP（证据音频 + 原始来源 +
    案例全量记录 + 核验报告 + SHA-256 清单），解包后可用
    sha256sum -c SHA256SUMS.txt 独立校验，无需本平台在场；
  · 引擎与版本信息在每条存证记录中如实标注。
