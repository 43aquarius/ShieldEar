声盾 ShieldEar：五层总体架构
数据流自上而下：采集 → 检测引擎 → 判决融合 → 业务 → 展示（浏览器端与服务端运行同构 TypeScript 引擎）
采集层ACQUISITION
浏览器麦克风流AudioWorklet 实时采集，16kHz 单声道 PCM
文件导入WAV 解码 / 拖拽上传，服务端统一重采样
现场合成挑战内置 TTS 合成通道，生成对照样本
↓
检测引擎层ENGINE（同构 TS，零第三方依赖）
滑动窗口管线2s 窗口 / 1s 步进（50% 重叠），流式逐窗分析
八维声学特征hnr / zcrCV / fluxCV / hfPeriodicity 等声码器指纹
逻辑回归评分z 标准化 + 类加权 L2 校准权重
窄带信道自适应300–3400Hz 电话信道参数切换
↓
判决融合层FUSION & DECISION
逐窗判决中值滤波 + EMA 平滑，输出逐窗合成概率
整段判决能量加权聚合有声窗，输出整段置信度
四级风险分级LOW / MEDIUM / HIGH / CRITICAL 阈值 0.35/0.55/0.75
↓
业务层SERVICE
风险分级提示判决话术 + 处置建议（回拨核实、96110 举报）
证据留存SHA-256 哈希 + 时间戳，WAV 证据落盘
服务端复核API 路由复算，双端一致性校验
核验报告可打印八章节取证报告
↓
展示层PRESENTATION（单页应用，零跳转演示）
实时鉴听波形画布 + 逐窗置信度曲线 + 告警脉冲
文件检测拖拽即测，特征剖面可解释展示
案例库历史检测案件与证据链查询
结果面板判决卡 + 时间轴 + 证据哈希链
浏览器端（实时鉴听）
AudioWorklet 采集
同构引擎（初判）
逐窗曲线渲染
本地告警脉冲/提示音
⇄
服务端（Next.js API）
同构引擎（复核）
Prisma / SQLite 存证库
evidence/ 证据落盘
案例与报告 API
说明：检测引擎层为纯 TypeScript 实现（FFT、自相关基音分析、特征与评分），在浏览器与服务端运行完全相同的代码，保证「客户端初判 + 服务端复核」的判决一致性与取证可复现性。
