从音频接入到风险处置的完整处理链路（2s 窗口 / 1s 步进，逐窗时延 < 10ms，判决时延 ≤ 1s）

5静音窗排除帧 RMS 能量判定，有效语音比例 < 22% 的窗口不参与判决
6八维声学特征提取hnr / hnrCV / fluxCV / jitter / zcrCV / hfFlatness / hfEnergyRatio / hfPeriodicity
