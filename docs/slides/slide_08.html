创新点 CONTRIBUTION 最想说的一个：把检测搬进通话里

从离线文件检测，到通话级实时流式

既有研究与同方向获奖作品做的都是事后检测一段文件；声盾的滑窗流式管线边通话、边判决、检出即告警——提前一分钟的告警，可能就直接拦下一笔转账。

RTF < 0.015
纯 CPU · 普通终端可部署
2s 窗 / 1s 步进
逐窗置信度实时刷新

可解释引擎 + 数据校准

判决可展开为八维特征对自然先验的偏离；校准流程主动证伪无效特征，可随样本扩展重拟合

检测—告警—存证—报告闭环

四级风险分级、可疑片段时间轴、SHA-256 证据链、案件编号与 PDF 核验报告，结论无须二次加工即可进入举报协查

现场自证的双哈希锚定

合成挑战把 TTS 原始输出与分析副本分别哈希入库：这份音频确由平台现场生成、无法事后构造

三个副点各服务主点：可解释让结论可信 · 闭环让结论可用 · 锚定让演示可验。
主创新先讲：既有研究和同方向获奖作品做的都是事后检测一段文件，声盾把检测搬进通话里——滑窗流式管线边通话、边判决、检出即告警，提前一分钟的告警可能直接拦下一笔转账。而纯 CPU 上 RTF 小于 0.015，2 秒窗、1 秒步进，逐窗置信度实时刷新。三个副点各一句：可解释引擎加数据校准，让结论可信；检测到报告的闭环，结论无须二次加工即可进入举报协查，让结论可用；双哈希锚定证明音频确由现场生成、无法事后构造，让演示可验。
