# 校准与测试数据集说明

本目录存放引擎校准与系统测试的**全部数据来源与逐条判决记录**，配合 `scripts/` 内的测试管
线可一键复现《声盾-系统测试报告》的全部结果。

## 文件清单

| 文件 | 说明 |
|------|------|
| `audio/*_16k.wav` | 自然人声源样本（5 段，16kHz 单声道）：wavesurfer.js / MDN 公开演示人声 + 公有领域有声书（LibriVox） |
| `audio/tts_*.wav` | 神经 TTS 合成样本（7 音色 × 3 文本，共 20 段，z-ai TTS 授权生成） |
| `features.json` | 权重拟合阶段的逐文件八维特征提取结果（与权重解耦的中间产物） |
| `results.json` | 权重拟合**之前**的引擎评估历史记录（保留用于对比，非当前结果） |
| `testsuite_results.json` | **当前引擎全量测试结果**：105 文件 × 双信道 = 210 条判决 + 微基准 + 全部汇总指标 |

## 鲁棒性变体的确定性再生

测试套件使用的变体样本（`nvar_*` 自然变体、`tvar_*` 合成退化变体）体积较大且完全可再
生，故不入库。两个生成脚本均使用**固定随机种子**，在任何机器上重跑得到逐字节一致的结
果：

```bash
bun scripts/gen-natural-variants.ts   # 自然：+6dB / -6dB / 1.05 变速 / 20dB 加噪（种子 20261027）
bun scripts/gen-tts-variants.ts       # 合成：20dB 加噪 / MP3 64kbps 编解码往返 / 1.05 变速（需 ffmpeg）
bun scripts/run-testsuite.ts          # 执行后即得 210 条判决
```

窄带（电话）信道仿真（300–3400Hz 带通 + 轻微底噪）内置于测试脚本，种子固定为 42。

## 数据合规

- 自然样本均来自公开渠道且采用公有领域或演示用途授权，不含可识别特定自然人的个人信息；
- 合成样本由授权 TTS 服务生成，不模仿任何真实人物音色；
- 本目录数据仅用于检测算法评测与研究。
